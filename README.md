# 🏋️ MERN Fitness Tracker | Iron VIP

A full-stack fitness tracking web application built with the **MERN stack** (MongoDB, Express.js, React, Node.js). It helps users log their workouts, track their progress, and stay consistent with their fitness goals.

🔗 **Live Demo:** [fitness-nu-ebon.vercel.app](https://fitness-nu-ebon.vercel.app/login)

---

## About the Project

Iron VIP is a fitness tracking platform where users can create an account, record their workouts, and keep an eye on their fitness journey in one place. The project demonstrates a complete MERN workflow: a React frontend, a REST API built with Express and Node.js, and MongoDB for data storage, deployed on Vercel.
