SECTION 3: SECURITY, PRIVACY & USAGE GUIDELINES
========================================================================================
1. Individual Data Privacy: Each user's logs, weight measurements, and personal health
   information are securely isolated to their specific user ID.
2. Password Requirements: Passwords must be at least 6 characters in length and are
   cryptographically hashed using bcrypt (salt rounds: 10) prior to database persistence.
3. Authentication Persistence: User sessions authenticate via JSON Web Tokens (JWT)
   valid for 30 days. Tokens are stored in browser localStorage and automatically attached
   to all outbound REST requests via Axios interceptors.
4. Offline Resilience: In the event of network disruption, the application seamlessly
   caches entries locally in browser localStorage, allowing uninterrupted logging.
5. Unit Configuration: Users can toggle between Metric (kg / cm) and Imperial (lbs / inches)
   directly within the User Settings panel (`/settings`).
